# DECISIONS

- 2026-09-27 요소 종류는 다 남기고, 같은 종류가 여러 벌이면 가장 나은 한 벌만 남긴다.
- 2026-09-27 값은 Fusion 값으로 적는다. 글자 폭은 Fusion 이 `DataWindow` 로 잰다. 폰트 파일로 추정한 폭과 렌더에서 되읽은 색은 쓰지 않는다.
- 2026-09-27 자막바는 플리마켓 것을 기준으로 한다. 여름방학 이름판은 이름 알약으로 합친다.
- 2026-09-27 질문·이지선다는 여름방학 구성을 자막바 모양(높이 110px, 같은 곡률)으로 다시 만든다.
- 2026-09-27 인트로 템플릿은 블랙매직 것이라 싣지 않고 바꾼 값만 적는다. 효과음도 빌린 것이라 싣지 않는다.
- 2026-09-27 폰트 파일은 싣지 않고 받는 곳만 적는다.
- 2026-09-27 라이선스는 MIT.
- 2026-09-27 색 기준 설정은 원본 플리마켓 프로젝트의 것(색 관리 v2, Rec.709 Scene, SDR 100)이다. 같은 값이 색 관리 없는 프로젝트에서는 짙게 보인다(speaker-3 #EB5904 → #D82301, 렌더로 확인). 화자 색이 원본대로 보이는 설정을 기준으로 삼고, 미리보기도 그 설정에서 뽑는다.
- 2026-09-27 색 관리 없는 프로젝트용 템플릿을 한 벌 더 만든다(`th01 … (색 관리 없음)`). 값은 기준 값에 BT.709 OETF 를 적용해 계산하고, 원본을 감싼 네 개의 색 입력에도 같게 적용한다.
- 2026-09-27 화면색으로 정한 색(벽, muted, 폼 데모 폼 색)은 hex 로 적고, 빌드가 BT.709 OETF 역함수로 기준 값을 계산한다.
- 2026-09-27 배치 값은 `tokens.json`(layout, form, intro, fade)에 둔다. 폼 데모 휴대폰 화면 안의 세부 배치만 `build/form.py` 에 둔다.
- 2026-09-27 폼 데모의 폼 글자 크기는 신청곡 홍보 영상 폼 장면의 Text+ Size 를 그대로 쓴다. 그 영상에서 픽셀 ÷ 1280 으로 정한 값이지만 원본 영상의 값이라 예외로 둔다.
- 2026-09-27 긴 글자는 Text+ 바로 뒤의 Transform 으로 글자만 줄이고, 상자는 높이·곡률을 두고 폭만 맞춘다. 이지선다 A·B 는 한 배율을 같이 쓴다.
- 2026-09-27 글자 폭은 1920 폭 단위로 맞춰 타임라인 해상도와 상관없이 비율을 지킨다.
- 2026-09-27 카드 템플릿은 벽 그라데이션을 스스로 갖고 기본으로 켠다. 영상 위에 얹을 때는 `벽` 을 0 으로 둔다.
- 2026-09-27 원본을 감싼 네 개에도 위치·크기 Transform 을 붙인다. 원본 노드 값은 바꾸지 않는다.
- 2026-09-27 빌드는 문법 검사나 순환 검사에 걸리면 설치하지 않는다.
